# Zyn Assistente — V2.0.8

Base: V2.0.7.

## Alterações
- Histórico de ganhos em lista compacta: valor/data na primeira linha e origem + editar/excluir na segunda.
- Modal de ajuste diário usa a mesma lista compacta e respeita a largura do celular.
- Campo de origem de ganho inclui Uber, Entregas e Outros.
- Importação de música local calcula fingerprint SHA-256 e ignora duplicatas; arquivos antigos também usam nome + tamanho como fallback.
- Mantidos os demais módulos e IndexedDB.
